# @wake-protocol/bytes

不変のバイト値、固定幅整数（`Byte` / `Byte2` / `Byte4` / `Byte8`）、ブランド型（`Brand` / `fixedLength`）を提供します。[WAKE Protocol](https://github.com/nozomi-hiragi/wake-protocol) 仮実装のコアライブラリです。

> [!WARNING]
> これは仕様の動作確認のための仮実装です。本番では使わないでください。

## インストール

```sh
# npm
npm install @wake-protocol/bytes

# JSR（npm など）
npx jsr add @wake-protocol/bytes

# JSR（Deno）
deno add jsr:@wake-protocol/bytes
```
