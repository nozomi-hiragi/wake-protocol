# @wake-protocol/codec

`Uint8Array` 用の LP（Length-Prefixed）エンコード、ASCII / Latin-1 / UTF-8 のテキスト変換を提供します。[WAKE Protocol](https://github.com/nozomi-hiragi/wake-protocol) 仮実装のコアライブラリです。

> [!WARNING]
> これは仕様の動作確認のための仮実装です。本番では使わないでください。

## インストール

```sh
# npm
npm install @wake-protocol/codec

# JSR（npm など）
npx jsr add @wake-protocol/codec

# JSR（Deno）
deno add jsr:@wake-protocol/codec
```
